# TwoTab Data Schema Documentation

This document describes the structure of data stored by TwoTab in the browser's storage, as well as the file formats used for import, export, and backup.

---

## 1. Local Storage Schema

TwoTab uses `chrome.storage.local` to store the user's saved tab groups under the key `tabGroups`. 

The value is a JSON array of **TabGroup** objects.

### JSON Representation Example

```json
{
  "tabGroups": [
    {
      "id": 1690000000000,
      "date": "2026-07-12T22:49:20.000Z",
      "name": "Project Research",
      "tabs": [
        {
          "title": "Google",
          "url": "https://www.google.com"
        },
        {
          "title": "GitHub - TwoTab",
          "url": "https://github.com/nickravesh/TwoTab"
        }
      ]
    }
  ]
}
```

### Fields Description

| Field | Type | Description |
| :--- | :--- | :--- |
| `tabGroups` | Array | Root array containing all tab groups, sorted chronologically descending in UI. |
| `tabGroups[].id` | Number | Unique identifier generated via `Date.now()`. Used for updating names or deleting groups. |
| `tabGroups[].date` | String | ISO 8601 timestamp representing when the group was saved. |
| `tabGroups[].name` | String | (Optional) Custom name assigned to the group. Defaults to `"Saved Group"` or `"Imported Group"` if not specified. |
| `tabGroups[].tabs` | Array | Array of tab objects saved in this group. |
| `tabGroups[].tabs[].title` | String | The title of the saved tab page. |
| `tabGroups[].tabs[].url` | String | The absolute URL of the saved tab page. |

## 2. File Import/Export & Backup Formats

TwoTab supports three kinds of file outputs: TXT backups, CSV backups, and Full CSV exports.

### A. TXT Backup Format (`TwoTab_newgroup_<timestamp>.txt`)
- **Generated by**: [background.js](file:///Users/ali/Documents/Programming/MyGitHub/TwoTab/background.js) on group creation.
- **Content**: Contains only the URLs from the newly saved group, with exactly one URL per line.
- **Format**:
  ```text
  https://www.google.com
  https://github.com/nickravesh/TwoTab
  ```

### B. CSV Backup Format (`TwoTab_fullbackup_<timestamp>.csv`)
- **Generated by**: [background.js](file:///Users/ali/Documents/Programming/MyGitHub/TwoTab/background.js) on group creation (incremental full backup).
- **Columns**: `GroupID,Date,Title,URL`
- **Formatting details**:
  - The title is wrapped in double quotes, and any internal double quotes are escaped as `""`.
  - Commas in URLs/Titles are handled natively.
- **Format**:
  ```csv
  GroupID,Date,Title,URL
  1690000000000,2026-07-12T22:49:20.000Z,"Google",https://www.google.com
  1690000000000,2026-07-12T22:49:20.000Z,"GitHub - TwoTab",https://github.com/nickravesh/TwoTab
  ```

### C. Full CSV Export Format (`twotab_export_<date>.csv`)
- **Generated by**: [tabs.js](file:///Users/ali/Documents/Programming/MyGitHub/TwoTab/tabs.js) when the user clicks "Export All".
- **Columns**: `Group ID,Group Name,Date,Title,URL`
- **Formatting details**:
  - Contains additional column for custom `Group Name`.
  - All string values (Name, Title, URL) are wrapped in double quotes.
- **Format**:
  ```csv
  Group ID,Group Name,Date,Title,URL
  1690000000000,"Project Research","2026-07-12T22:49:20.000Z","Google","https://www.google.com"
  1690000000000,"Project Research","2026-07-12T22:49:20.000Z","GitHub - TwoTab","https://github.com/nickravesh/TwoTab"
  ```

## 3. Parsing and Import Logic

When importing via [tabs.js](file:///Users/ali/Documents/Programming/MyGitHub/TwoTab/tabs.js) (`importTabs()`):
- **TXT Files**: Every line that is not empty is treated as a URL. The title of the tab is initialized to the URL itself.
- **CSV Files**:
  - Splitted by newlines and commas (naive parsing: `line.split(',')`).
  - Expects the structure to be `Title,URL` or `URL` only. If a line splits into multiple parts, it checks if the second column exists and treats it as the URL, otherwise the first column is the URL.
  - Skips rows that don't start with `http` in their URL field.
  - Unquotes strings by replacing starting/ending double quotes: `.replace(/^"|"$/g, '')`.
- **JSON Files**: Currently `.json` is accepted in the file selection filter (`accept=".txt,.csv,.json"`), but the parsing logic inside [tabs.js](file:///Users/ali/Documents/Programming/MyGitHub/TwoTab/tabs.js) does not implement JSON parsing yet.
